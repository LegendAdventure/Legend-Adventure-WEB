# Legend Adventure WEB

Este proyecto trata de un juego chat, rpg. Basado en los conocimientos
adquiridos durante el ciclo,\
El proposito de este proyecto es cumplir un sueño que ha perdurado y ahora hemos conseguido gracias a los conocimientos obtenidos ir desarrollando este juego.

---

## Stack Tecnológico

| Capa | Framework |
|------|-----------|
| **Backend** | NestJS (Node.js + TypeScript) |
| **Frontend** | React + Vite |
| **Base de datos** | PostgreSQL |
| **ORM** | Prisma |
